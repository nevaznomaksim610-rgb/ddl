# Бот дедлайнов ВШМ

Node.js 24, клиент удалённой базы — `@libsql/client`. Токен и секреты хранятся в env-файлах и переменных Vercel, данные production — в отдельной базе Turso.

## Production Vercel

Проект `study-mate1/gsom-deadlines-bot`. Telegram получает ответы через защищённый webhook `/api/telegram`; `/api/health` проверяет подключение к базе. Данные и незавершённые шаги регистрации сохраняются в Turso. Одновременные отправители используют блокировку записи очереди на 90 секунд, чтобы не отправлять одно сообщение дважды. При временной ошибке доставки webhook возвращает 503, и Telegram повторяет обновление без повторного создания задания.

Планировщик Vercel: `/api/daily` каждый день в 06:00 UTC, `/api/reminders` каждый день в 15:00 UTC. Второй endpoint учитывает выбранный админом режим, включая еженедельный. На Hobby фактический запуск возможен в пределах часа: 09:00–09:59 и 18:00–18:59 МСК. Endpoints принимают только запросы с `Authorization: Bearer CRON_SECRET`.

Переменные production: `BOT_TOKEN`, `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `WEBHOOK_SECRET`, `CRON_SECRET`, `DAILY_HOUR=9`, `ADMIN_REMINDER_HOUR=18`. Для управления админами команда `npm run admin` использует удалённую базу, если `TURSO_DATABASE_URL` задан в `.env`. Токены в sensitive-переменных Vercel нельзя скачать через `vercel env pull`; локальные секретные копии сохранены в `.env.database` и `.env.deployment`.

```powershell
npm test
npx vercel deploy --prod --yes
```

Не запускать локальный polling одновременно с production webhook. Локальная база `data/bot.sqlite` остаётся резервной копией на момент переноса.

## Пользователь

- `/start`: курс → направление → группа. Регистрация сохраняется один раз.
- `/status`: все активные задания группы, включая просроченные, по возрастанию даты.
- `/notifications`: ежедневная сводка в 09:00 МСК (ближайшие 7 дней и просроченные), только новые работы и изменения, либо отключение. По умолчанию — новые работы.
- `/id`: Telegram ID для выдачи админки владельцем.

Первый курс (набор 2026, ключи `management1`, `public1`, `international1`): менеджмент 26.Б01–26.Б08, ГМУ 26.Б10, международный менеджмент 26.Б13/26.Б14. Группы и предметы взяты из timetable.spbu.ru/GSOM 06.10.2026: основные дисциплины осеннего семестра без элективов английского, РКИ и физкультуры; для международного менеджмента — английские названия.

Второй курс: менеджмент 25.Б01–25.Б08, ГМУ 25.Б10/25.Б11, международный менеджмент 25.Б13/25.Б15. Номера групп второго курса сверены с timetable.spbu.ru/GSOM. Названия направлений и предложенные предметы взяты из предоставленных изображений; ГМУ позволяет вводить предмет вручную.

## Админ группы

Права выдаются только локальной командой владельца; пользователь не может назначить себя админом. Одна группа — один админ. Если права выданы до регистрации без группы, админ выбирает её в `/start`; если после регистрации — назначается уже выбранная группа.

```powershell
npm run admin -- users
npm run admin -- grant 123456789
npm run admin -- grant @username
npm run admin -- grant 123456789 '25.Б01-вшм'
npm run admin -- admins
npm run admin -- revoke 123456789
```

Выдача по username работает после первого `/start`. Чтобы заменить админа, сначала отозвать права прежнего, затем выдать новому. Telegram ID — постоянный идентификатор назначения; переименование username не передаёт права другому человеку.

`/admin` открывает добавление по типу и дате, ручной ввод, список для редактирования, закрытия и удаления. `/add` сразу запускает ручной ввод. Типы: домашняя работа, контрольная, сессия. В быстром режиме предмет и описание необязательны. Даты вводятся как `ДД.ММ.ГГГГ` или выбираются кнопками. Дедлайн без времени действует до конца дня по Москве. Перед сохранением показывается карточка подтверждения; `/cancel` отменяет ввод.

Изменение названия, даты, типа и описания доступно только админу назначенной группы. Закрытые и удалённые задания сохраняются в БД, но исчезают из `/status`. Создание, изменение и закрытие фиксируются в журнале `audit`. Уведомления о добавлении, изменении и отмене получает только соответствующая группа в режиме «новые работы».

Напоминание админу: по понедельникам в 18:00 МСК, с выбором ежедневного режима или отключения. Это отдельная настройка, не меняющая уведомления студента. Кнопка «Расписание актуально» записывает проверку в журнал.

## Запуск

```powershell
# Первый запуск: скопировать .env.example в .env и указать токен
npm test
npm start

# Фоновый запуск Windows с перезапуском после аварий
.\start.ps1
.\stop.ps1
```

Для отдельного локального режима на Windows с ограничениями выполнения скриптов:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

`start.ps1` запускает скрытый supervisor. Логи — `logs/bot.log` и `logs/bot-error.log`; состояние опроса — `data/health.json`. Повторный запуск защищён PID-файлами. Неверный токен, конфликт другого polling-процесса или существующий webhook останавливают запуск. Скрипт не отключает чужой webhook и не очищает накопленные обновления Telegram.

Локальный режим требует включённого компьютера. Production Vercel использует Turso и не зависит от этого компьютера. Локальная SQLite не используется как постоянное хранилище serverless.

Состояние регистрации, незавершённые мастера, права, задания, offset Telegram и очередь исходящих сообщений сохраняются в SQLite. Обработка каждого входящего update транзакционная; повтор update не создаёт работу заново. Ежедневная сводка создаётся один раз на пользователя за московскую дату. После простоя сводка текущего дня отправляется при запуске, если время отправки уже наступило; пропущенные дни не рассылаются.

Очередь повторяет отправку при сетевой ошибке и соблюдает `retry_after` Telegram. Блокировка бота отключает доставку пользователю до нового обращения. Telegram `sendMessage` не поддерживает ключ идемпотентности: при аварии строго между принятием сообщения Telegram и записью результата в SQLite возможен повтор сообщения.

Сохранять резервную копию SQLite при остановленном боте, либо использовать API SQLite backup. Не копировать только основной файл работающей базы без учёта WAL. `.env`, база и логи исключены из Git. API: [официальная документация Telegram](https://core.telegram.org/bots/api).
